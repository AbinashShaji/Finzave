How FinZave Works

Workflow

From financial data to meaningful financial insights.

See how FinZave takes your financial information through recording, calculation, analysis and rule-based evaluation to produce useful insights.

Input → ↓ Record → ↓ Calculate → ↓ Analyze → ↓ Evaluate → ↓ Insight → ↓ Decide

How It Works

01

Input

Input User enters financial information such as income, expenses and goals.
02

Record

Process FinZave stores and organizes the entered information securely.
03

Calculate

Process FinZave performs the core financial calculations.
Output
Income − Total Expenses = Savings
04

Analyze

Process FinZave analyzes financial records, spending patterns and implemented financial metrics (e.g. savings rate, category breakdowns).
05

Evaluate

Process The rule-based logic evaluates the user's financial conditions against predefined rules.
06

Insight

Output The system converts analysis results into understandable financial insights and recommendations.
07

Decide

Output The user uses the information to make more informed spending, saving or planning decisions.

Rule-Based Logic

FinZave uses predefined, transparent rules to evaluate financial conditions. It does not use a trained machine-learning model to generate recommendations.

FINANCIAL DATA → CALCULATED METRICS → PREDEFINED RULES → CONDITION CHECK → MATCH → INSIGHT
IF Total Expenses > 80%
THEN Issue Warning

Dashboard Role

The dashboard acts as the visualization layer. It is where processing and analysis are outputted to the user.
